Параметрическая модель

Три полых фазных проводника и три коаксиальные оболочки. Прямолинейный участок. Расчёт FEMM не меняется при редактировании геометрии.

Условные опорные конструкции и торцевые подключения здесь не показаны. Окно — только режим просмотра, не физическое отверстие в оболочке.

Расчёт

Проверяем входные данные, формируем расчётное задание и экспортируем Lua-сценарий для установленного FEMM 4.2.

Условия задачи

Проверка постановки

FEMM здесь не запускается. Кнопка создаёт воспроизводимое задание. Для запуска на GitHub Actions или Windows понадобится отдельный исполнитель.

Ток в Lua задаётся амплитудой √2 × RMS. Изменение геометрии создаёт новый расчёт, а не перезаписывает старый.

Добавить полученный результат

Ни один пользовательский результат ещё не загружен.
Загружаются расчёты FEMM из GitHub Actions…

Для экспорта полей и потерь используй приложенный make_result.py. Результат привязывается ко всем расчётным параметрам, а не только к диаметрам.
