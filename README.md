# IPB Studio

Веб-интерфейс для анализа трёхфазного генераторного токопровода с пофазно-экранированными проводниками по примеру 31.1 К. К. Агравала.

## Демонстрация

Сайт GitHub Pages: https://trashchenkov.github.io/ipb-studio/

Чтобы впервые включить публикацию, владелец репозитория должен открыть **Settings → Pages → Build and deployment → Source** и выбрать **GitHub Actions**. После этого workflow `Publish IPB Studio to GitHub Pages` запускается при push в `main` или вручную.

## Возможности

- Конструкция: размеры и проверка геометрии
- Расчёт: подготовка JSON/Lua для FEMM, импорт результатов
- Результаты: магнитное поле, токи оболочек, потери
- Сравнение: два сохранённых варианта

`index.html` автономен и содержит исходные результаты FEMM для двух идеализированных электрических схем оболочек. При изменении геометрии прежние результаты не пересчитываются.

**Выполнение FEMM:** сайт подготавливает полное JSON-задание; пользователь с правом записи запускает [Calculate IPB using FEMM (Windows)](https://github.com/trashchenkov/ipb-studio/actions/workflows/femm.yml). GitHub-hosted Windows runner выполняет FEMM 4.2 и сохраняет проверенные результаты в `results/`. После публикации Pages сайт загружает результаты автоматически. Безопасный запуск одной кнопкой непосредственно с GitHub Pages не реализован.

Численные результаты не являются экспериментальной валидацией конструкции.

## Как выполнить свой расчёт FEMM

1. Откройте [IPB Studio](https://trashchenkov.github.io/ipb-studio/), задайте конструкцию и перейдите на вкладку **«Расчёт»**.
2. Проверьте условия, нажмите **«Скопировать JSON»**.
3. Войдите в GitHub с аккаунтом, имеющим **write-доступ** к этому репозиторию, и откройте [Calculate IPB using FEMM (Windows)](https://github.com/trashchenkov/ipb-studio/actions/workflows/femm.yml).
4. В меню **Run workflow** выберите `main`, вставьте JSON в **job_json** и подтвердите **Run workflow**. Остальные переключатели GitHub игнорируются, если передан JSON.
5. Дождитесь успешного расчёта, затем успешной публикации результатов и GitHub Pages. Вернитесь на сайт, нажмите **«Обновить результаты»** и выберите новый запуск в **«Результатах»** или **«Сравнении»**.

**Почему нет кнопки автоматического запуска?** GitHub Pages — статический сайт. Чтобы отправить задание в приватизированный Actions API, требуется авторизация с правом записи. Мы не сохраняем пользовательские GitHub-токены в браузере. Поэтому расчёт запускается только в официальном интерфейсе GitHub. Результаты публикуются автоматически, параметры расчётов общедоступны. FEMM на компьютере пользователя не нужен.

**Ограничения:** это экспериментальная 2D гармоническая модель; вычисления FEMM не заменяют проектной проверки изоляции, нагрева, электродинамических усилий и работы в аварийных режимах.

## Аварийные режимы — предварительные оценки (этап 1)

На вкладке **«Расчёт» → «КЗ: силы и нагрев»** доступны сценарии **ABC, AB, BC, CA**. Вводятся действующее значение периодической составляющей тока повреждения, эквивалентное отношение X/R, угол включения и продолжительность повреждения. Эти значения **задаются пользователем**, а не рассчитываются по схеме генератора и сети.

- Токи описываются аналитической синусоидой с затухающей апериодической составляющей; для двухфазного КЗ токи повреждённых фаз равны и противоположны. Постоянная времени τ=(X/R)/(2πf).
- Погонные усилия рассчитаны по приближению **бесконечных параллельных линейных токов по осям фаз**; результаты в Н/м или кН/м. Это не интеграл по объёму реального проводника и не расчёт электромагнитных сил в FEMM.
- Увеличение температуры рассчитано по адиабатической модели алюминиевого полого проводника, с заданной теплоёмкостью 900 Дж/(кг·К), плотностью 2700 кг/м³ и зависимостью ρ(T) из текущих параметров материала. Используется полное металлическое сечение и заданный ток i(t); теплопередачи и skin/proximity-эффекта нет.
- Приводятся временные графики погонной силы, максимальные токи/силы, интегралы i²dt и конечные температуры *проводников*. Оболочки и их нагрев в этой версии не учитываются.
- Замыкания **на землю и на оболочку** в интерфейсе обозначены как недоступные, поскольку требуют электрической модели нейтрали, заземления, путей тока и/или локальной трёхмерной постановки.
- **Нельзя** использовать эти результаты как проверку термической или электродинамической стойкости, оценки реальных пиковых усилий на опоры, токов со стороны генератора и сети или последствий КЗ в производственной конструкции.

Следующие этапы: уточнение токов КЗ по эквивалентной схеме источников, распределение электродинамических усилий через расчёт поля, токи в оболочках, тепловая задача с охлаждением и модель опор/напряжений.
