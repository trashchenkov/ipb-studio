# IPB Studio

Инженерный прототип исследования трёхфазного генераторного токопровода с пофазно-экранированными проводниками.

Веб-интерфейс охватывает четыре шага: **Конструкция → Расчёт → Результаты → Сравнение**.

Исходные данные основаны на примере 31.1 K. C. Agrawal, *Industrial Power Engineering and Applications Handbook*. В демонстрации использованы результаты FEMM 4.2 для двух идеализированных вариантов соединения оболочек.

## Публикация

Содержимое подготовленного архива `ipb_studio_pages_ready.zip` необходимо загрузить **в корень репозитория** (не сам ZIP): `index.html`, `app.js`, `generate_femm.py`, `make_result.py`, `.nojekyll` и документацию.

После загрузки выберите **Settings → Pages → Build and deployment → Source → GitHub Actions**. Публикацию выполняет `.github/workflows/pages.yml`.

Сайт: https://trashchenkov.github.io/ipb-studio/

**GitHub Pages — статический хостинг.** Изменение параметров само по себе не запускает FEMM: в текущем прототипе расчёт выполняется отдельно, а результаты импортируются в веб-приложение. Токи КЗ, тепловые и механические режимы не подтверждены численным расчётом в данном прототипе.
