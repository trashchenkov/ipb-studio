# IPB Studio

Веб-интерфейс для анализа трёхфазного генераторного токопровода с пофазно-экранированными проводниками по примеру 31.1 К. К. Агравала.

## Демонстрация

Сайт GitHub Pages: https://trashchenkov.github.io/ipb-studio/

Чтобы впервые включить публикацию, владелец репозитория должен открыть **Settings → Pages → Build and deployment → Source** и выбрать **GitHub Actions**. После этого workflow `Publish IPB Studio to GitHub Pages` запускается при push в `main` или вручную.

## Возможности

- Конструкция: размеры и проверка геометрии
- Расчёт: подготовка JSON/Lua для FEMM, импорт результатов
- Результаты: магнитное поле, токи оболочек, потери
- Сравнение: два сохранённых варианта

`index.html` автономен и содержит исходные результаты FEMM для двух идеализированных электрических схем оболочек. При изменении геометрии прежние результаты не пересчитываются.

**Ограничение:** GitHub Pages не запускает FEMM. Веб-сайт готовит задания и принимает результаты локально выполненных расчётов. Запуск FEMM в GitHub Actions ещё не реализован.

Численные результаты не являются экспериментальной валидацией конструкции.
