# IPB Studio

Веб-интерфейс для анализа трёхфазного генераторного токопровода с пофазно-экранированными проводниками по примеру 31.1 К. К. Агравала.

## Демонстрация

Сайт GitHub Pages: https://trashchenkov.github.io/ipb-studio/

Чтобы впервые включить публикацию, владелец репозитория должен открыть **Settings → Pages → Build and deployment → Source** и выбрать **GitHub Actions**. После этого workflow `Publish IPB Studio to GitHub Pages` запускается при push в `main` или вручную.

## Возможности

- Конструкция: размеры и проверка геометрии
- Расчёт: подготовка JSON/Lua для FEMM, импорт результатов
- Результаты: магнитное поле, токи оболочек, потери
- Сравнение: два сохранённых варианта

`index.html` автономен и содержит исходные результаты FEMM для двух идеализированных электрических схем оболочек. При изменении геометрии прежние результаты не пересчитываются.

**Выполнение FEMM:** сайт подготавливает полное JSON-задание; пользователь с правом записи запускает [Calculate IPB using FEMM (Windows)](https://github.com/trashchenkov/ipb-studio/actions/workflows/femm.yml). GitHub-hosted Windows runner выполняет FEMM 4.2 и сохраняет проверенные результаты в `results/`. После публикации Pages сайт загружает результаты автоматически. Безопасный запуск одной кнопкой непосредственно с GitHub Pages не реализован.

Численные результаты не являются экспериментальной валидацией конструкции.

## Как выполнить свой расчёт FEMM

1. Откройте [IPB Studio](https://trashchenkov.github.io/ipb-studio/), задайте конструкцию и перейдите на вкладку **«Расчёт»**.
2. Проверьте условия, нажмите **«Скопировать JSON»**.
3. Войдите в GitHub с аккаунтом, имеющим **write-доступ** к этому репозиторию, и откройте [Calculate IPB using FEMM (Windows)](https://github.com/trashchenkov/ipb-studio/actions/workflows/femm.yml).
4. В меню **Run workflow** выберите `main`, вставьте JSON в **job_json** и подтвердите **Run workflow**. Остальные переключатели GitHub игнорируются, если передан JSON.
5. Дождитесь успешного расчёта, затем успешной публикации результатов и GitHub Pages. Вернитесь на сайт, нажмите **«Обновить результаты»** и выберите новый запуск в **«Результатах»** или **«Сравнении»**.

**Почему нет кнопки автоматического запуска?** GitHub Pages — статический сайт. Чтобы отправить задание в приватизированный Actions API, требуется авторизация с правом записи. Мы не сохраняем пользовательские GitHub-токены в браузере. Поэтому расчёт запускается только в официальном интерфейсе GitHub. Результаты публикуются автоматически, параметры расчётов общедоступны. FEMM на компьютере пользователя не нужен.

**Ограничения:** это экспериментальная 2D гармоническая модель; вычисления FEMM не заменяют проектной проверки изоляции, нагрева, электродинамических усилий и работы в аварийных режимах.

## Аварийные режимы по К. К. Агравалу (топология повреждения)

Вкладка **«Расчёт» → «Короткое замыкание: где находится повреждение?»** содержит три постановки:

1. **Испытание прямого участка, §32.3.5.** Питание подано с одного конца, фазы замкнуты на другом. Доступны трёхфазное испытание ABC и двухпроводное испытание соседних фаз AB/BC. Исходный пример 31.1 даёт характеристику стойкости **122 кА на 1 с**; это не вычисленный ток КЗ. Для однофазного питания §32.3.5 рассматривает около 93% от указанного трёхфазного испытательного тока. Значение в интерфейсе вводится вручную.
2. **Повреждение на главном токопроводе G—GT, §13.4.1(5).** Показываются отдельные участки от генератора и от повышающего трансформатора до места КЗ. Токи 61 и 40 кА — пример входных условий из книги, а не результат расчёта импедансов в IPB Studio. Они **не суммируются в одном сечении главного токопровода**. Положение повреждения по длине пока только схематическое; в электрической схеме нет продольных импедансов и положения источников.
3. **Повреждение на ответвлении к UAT, пример 13.3.** На ответвлении токовые вклады суммируются: **61 + 40 = 101 кА**, а расчётный пиковый ток автора при множителе 2,5 — **252,5 кА**. Для главного токопровода оценки сил и нагрева выполняются отдельно на стороне G (61 кА) и GT (40 кА); силы и нагрев самого ответвления **не выводятся**, потому что геометрия ответвления пока не задана.

Для прямых участков оцениваются временная форма токов, погонные силы между линейными токовыми нитями и адиабатическое повышение температуры алюминиевых фазных проводников. **Это не FEMM и не тепломеханическая проверка**: нет путей тока по оболочкам, сил на оболочки, оснастки, геометрии ответвления, локальной модели зоны повреждения, реальных переходных токов генератора, теплопередачи, проверки изоляции и опор. Значения **X/R**, угол и длительность задаются пользователем и не выводятся из параметров электростанции. Результаты служат учебно-исследовательской оценкой последствий заданных аварийных токов, не подтверждением допустимости конструкции.

**Следующая техническая задача:** отдельные проверяемые токовые схемы с импедансами источников и продольными параметрами ветвей, а затем расчёты электродинамических сил и тепла с учётом распределения тока внутри металла и оболочек (FEMM и тепловая модель).

## Расчёт трёхфазного КЗ по эквивалентной схеме R + jX

В сценариях **«Повреждение на главном токопроводе»** и **«КЗ на ответвлении UAT»** добавлен выбор способа задания токов:
- **Исходные данные Агравала** — по умолчанию назначенные токи 61 и 40 кА RMS (и их арифметическая сумма 101 кА на ответвлении в рамках исходного примера).
- **Эквивалентная сеть R + jX** — в качестве *новых входных данных модели* задаются линейное напряжение двух синфазных источников, их комплексные сопротивления на фазу, протяжённость главного токопровода и его погонные R/X; для UAT задаётся отдельное эквивалентное сопротивление ответвления. Эти значения **не взяты из книги**, а служат настраиваемой иллюстрацией.

Реализация: [`circuit.js`](circuit.js) — независимый модуль фазорного расчёта, [`fault.js`](fault.js) — интерфейс и предварительная оценка нагрузок. При трёхфазном металлическом повреждении на главной линии для каждого источника рассчитывается `I_G = E/Z_G(x)`, `I_GT = E/Z_GT(L-x)`; один и тот же ток **не** приписывается всем участкам линии. При повреждении на ответвлении решается узловое уравнение с третьей комплексной ветвью `Z_UAT`; ток ответвления `I_UAT=I_G+I_GT` складывается **как комплексный фазор**, поэтому его RMS не обязательно равен сумме действующих значений обоих вкладов.

**Границы применимости:** модель только прямой последовательности, синфазные внутренние ЭДС фиксированной величины, линейные неизменные R+jX, симметричное трёхфазное металлическое КЗ. Нет нулевой/обратной последовательностей, заземления нейтрали, насыщения, субпереходных постоянных времени генератора, коммутации, стандартизованных коэффициентов IEC 60909 и расчётов КЗ на землю. Для построения *приближённых* временных токов используются модуль и фаза рассчитанного тока с простым экспоненциальным членом; это не строгая динамика многомашинной системы. Силы и нагрев остаются упрощёнными аналитическими оценками для главного токопровода; **силы и нагрев ответвления UAT не рассчитываются без его геометрии**.

Проверки: `node --test tests/*.test.js`; GitHub Actions `Verify electrical models`. Тесты покрывают узловой баланс комплексных токов, влияние места КЗ и сопротивления ответвления, а также регрессию исходных сценариев.
