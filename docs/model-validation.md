# Проверка электромагнитной и тепловой модели IPB Studio

## Назначение

Демонстрационная модель трёхфазного генераторного токопровода, прямолинейное сечение.
Оценка пригодна для исследовательского сравнения схем и параметров, **не для подтверждения стойкости промышленной конструкции**.

## 1. Контроль электромагнитного расчёта

Исследуемая задача: двухфазное испытание AB с фазными токами +20 и −20 кА действующего значения, фаза C = 0, 50 Гц. FEMM решает гармоническую задачу без апериодической составляющей КЗ.

Для каждого из двух вариантов соединения оболочек (**bonded / isolated**) выполнить три расчёта:
- максимальный размер элемента в металле 4 мм;
- 2 мм;
- 1 мм.

В каждом расчёте сохранять:
- полные входные данные, версия генератора модели, частота, температура металла;
- токи проводников и оболочек как комплексные фазоры;
- погонные потери в проводниках и оболочках;
- силы Лоренца, средняя и комплексная составляющая 2f по каждой области (интегралы FEMM 11–14);
- силы по взвешенному тензору напряжений Максвелла (18–21);
- сетку магнитного поля.

**Не усреднять** два метода получения сил. Отдельно анализировать расхождения: интегралы силы могут быть малы относительно локальных сил в металле и чувствительны к сетке.

## 2. Критерии проверки

Ниже — **внутренние целевые критерии**, не нормы IEC:
- потери: изменение при h=2 → h=1 менее 1% для суммарных и каждой металлической области;
- существенные силы: изменение при h=2 → h=1 менее 5%, причём отдельно сравниваются средняя и 2f части;
- близкие к нулю силы: не использовать относительные проценты, указывать абсолютную невязку в Н/м;
- сверять суммарные токи проводников со входными фазорами;
- изолированные оболочки: суммарный продольный ток каждой оболочки близок к нулю, но её вихревые токи и потери могут быть ненулевыми;
- для соединённых оболочек проверять выполнение физической модели замыкания токов на концах; объединённая FEMM-цепь пока лишь идеализированное условие.

При неисполнении любого критерия — измельчить сетку и проверить расстояние до внешней границы, свойства материалов и электрические соединения.

## 3. Тепловая модель

На вкладке **«Результаты»** используется двухузловой стационарный баланс в каждом пофазном сечении:
- фиксированные потери проводника и оболочки из конкретного расчёта FEMM;
- теплообмен проводник → внутренняя поверхность оболочки (эффективная конвекция и излучение между концентрическими поверхностями);
- теплообмен наружная оболочка → окружающий воздух (конвекция и излучение).

Задаются пользователем: температура окружающего воздуха, эффективные коэффициенты теплоотдачи в зазоре и снаружи, излучательные способности **трёх поверхностей** — наружной поверхности проводника, внутренней поверхности оболочки и наружной поверхности оболочки. Излучение в зазоре использует первые две, излучение в окружающую среду — последнюю. По умолчанию наружной поверхности оболочки приписано ε = 0,65 как предварительное литературное значение для светло-серого покрытия, но оно **не распространяется автоматически на внутреннюю поверхность**. Вход `eps_shell_inner` является необязательным для программной совместимости: при его отсутствии используется старое значение `eps_shell`; новые расчёты через интерфейс задают их раздельно. Изначальные числа в интерфейсе **не получены от изготовителя и не прошли валидацию**.

Проверка: для каждого сечения **P_проводника = Q_зазор** и **P_оболочки + Q_зазор = Q_наружу** с малой численной невязкой. Температуры проводников и оболочек не возвращаются в FEMM для перерасчёта электропроводности — нет самосогласованного электро-теплового решения.

Не включены: теплоотвод по длине, опоры и фланцы, вентиляция каналов, движение воздуха в зазоре, теплообмен соседних оболочек, внешнее солнце и т. п. При КЗ тепловой процесс времени не рассчитывается этим модулем.

## 4. Какие исходные данные потребуются для перехода к изделию

- Электрическое присоединение оболочек: перемычки, шунты, заземление и реальные пути обратного тока на концах; возможные переходные сопротивления.
- Материалы, толщина стенок, поверхностная обработка и состояние алюминия, эмиссивность.
- Ориентация и способ прокладки токопровода (воздух/канал/галерея), вентиляция, температура среды.
- Геометрия изоляторов, опор, шаг крепления, конструкция сопряжений и допускаемые деформации.
- Для КЗ: реальные параметры генератора (включая субпереходные величины), трансформатора, сети и защит.

Пока это не известно, новые результаты следует обозначать **оценочными для условной модели**, а не инженерной аттестацией.

## 5. Методика сил FEMM и публикация результатов

Официальные источники по методам расчёта сил:
- [Руководство FEMM 4.2](https://www.femm.info/Archives/doc/manual42.pdf): интегралы силы Лоренца 11–14 и взвешенного тензора Максвелла 18–21.
- [FAQ FEMM — расчёт сил](https://femm.info/doku/doku.php?id=faq): рекомендуемая проверка по взвешенному тензору напряжений и уточнение сетки в воздушных зазорах.
- [Пример расчёта гармонической силы FEMM](https://www.femm.info/doku/doku.php?id=acforceexample): временная средняя и компонент на удвоенной частоте; комплексные результаты требуют правильной интерпретации пиковой нормировки.

Силы двух источников при КЗ **не** складываются в одном прямолинейном сечении, если токи направлены навстречу к повреждению с разных концов. Для каждого участка следует формировать собственную геометрию/электрический токовый режим. Входные данные замыканий на землю и КЗ внутри оболочки в существующей FEMM-модели отсутствуют.

Тепловая карточка **умышленно не показывает стационарные температуры для аварийных гармонических случаев**: за короткое КЗ стационарная температура не устанавливается. Временное увеличение температуры при КЗ пока оценивается отдельной адиабатической моделью в модуле аварийных режимов, не связанным с неоднородным распределением потерь в FEMM.
