# Электрическая схема оболочек генераторного токопровода — аудит постановки FEMM

Дата: 25 ноября 2026 г.

## Источники и их ограничения

- К. К. Агравал, *Industrial Power Engineering and Applications Handbook*, гл. 31, §§31.2.1–31.2.2, пример 31.1. В примере используются электрически непрерывные оболочки. Их межфазные соединения на крайних концах образуют контуры индуцированных токов.
- Руководство FEMM 4.2, *Circuit Properties*: цепь типа **parallel** (`mi_addcircprop(...,0,0)`) задаёт равное продольное падение напряжения для всех областей одной цепи, а их суммарный ток равен заданному значению. [Официальное руководство](https://www.femm.info/doku/lib/exe/fetch.php?media=upload%3Afiles%3Amanual.pdf), [официальный FAQ](https://www.femm.info/doku/doku.php?id=faq).

## Соответствие в текущей двумерной модели

Модуль `femm/generate.py` назначает всем трём оболочкам *одну* параллельную FEMM-цепь `bonded_shells` с общим заданным током **0 A**. Поэтому FEMM должен обеспечить:

1. одинаковое комплексное падение напряжения вдоль трёх оболочек;
2. баланс фазоров продольных токов: `I_shell,A + I_shell,B + I_shell,C ≈ 0`;
3. распределение продольных токов по импедансам с учётом электромагнитного взаимодействия.

Это **эквивалентная идеализация** оболочек, соединённых на **обоих концах** идеально проводящими перемычками, когда нет дополнительных продольных путей через землю или конструкции. Сама межфазная перемычка в двухмерной геометрии **не нарисована**; модель действует посредством связи электрических областей. Электрическое заземление не представлено отдельной ветвью.

Для `isolated` каждой из трёх оболочек назначена **своя отдельная** параллельная цепь с заданным током 0 A. Это запрещает **суммарный** продольный ток каждой оболочки, но не локальные вихревые токи и потери внутри металла.

## Новые проверки

Скрипт FEMM теперь сохраняет `circuits_bonded.csv` или `circuits_isolated.csv` с комплексными значениями тока, падения напряжения и потокосцепления цепей. `femm/process.py` проверяет имена цепей, конечность значений и отсутствие внешнего продольного тока в идеализированной системе оболочек. Новые результаты включают строковое описание предположенной схемы в `result.shell_connection_assumption`.

Остаются открытыми вопросы:
- сопротивление и индуктивность конечных перемычек;
- возможные пути возврата через другие металлические конструкции, заземляющие сети и грунт;
- распределение токов в торцевых частях, фланцах, поворотах и ответвлениях;
- распределение и локальные воздействия внутри опор и креплений.

Поэтому результаты FEMM для непрерывных оболочек **не подтверждают автоматически** реальные силы и потери на конкретном изделии.

## Охлаждение

Для наружной светло-серой поверхности в качестве литературного исходного значения Агравала принято **ε = 0,65** (не аттестационная характеристика). Эффективные коэффициенты теплоотдачи в зазоре и снаружи оставлены изменяемыми: их нельзя вывести из одного только коэффициента излучения. Тепловой интерфейс отдельно предупреждает, что эти параметры требуют проверки для конкретной прокладки/вентиляции.

## Решение

Для проверки расчётного примера 31.1 следует считать исходным вариантом **bonded, идеальное межфазное соединение на обоих концах**. Вариант **isolated** оставлять сравнительным. Указывать, что оба варианта — идеализированные граничные условия двумерной модели, а не схемы конкретного предприятия.
